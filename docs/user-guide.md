# 如何使用 Talk2 完成一场节点演讲

本指南覆盖内容编辑、路径组织、提词控制、项目备份和可验证的故障处理方式。

## 前置条件

按照[从源码运行 Talk2](getting-started.md)启动应用，或安装由项目发布流程生成的 Windows x64 NSIS 安装包。

## 如何组织讲稿

1. 在资料库中创建或打开演讲。
2. 直接编辑节点正文。粘贴结构化 Markdown 时，编辑器会转换标题、列表、代码块、引用、表格和块公式。
3. 粘贴 HTML 时，编辑器会删除脚本、样式、iframe、对象、嵌入内容、表单和事件属性后再插入。
4. 粘贴、拖入或通过工具栏选择图片。单张图片上限为 20 MB，且 MIME 类型必须以 `image/` 开头。
5. 双击节点标题进行重命名；拖动标题栏移动节点；选中节点后拖动边框调整尺寸。

`\(...\)`、`\[...\]`、`$...$` 和 `$$...$$` 中的公式会迁移为 Tiptap 数学节点。类似 `$100` 的普通价格文本不会被当作公式。

## 如何建立演讲顺序

1. 从前一节点的右侧连接点拖到后一节点的左侧连接点。
2. 为第一段内容选择“设为起点”。新项目默认以“开场”节点为起点。
3. 选择“开始演讲”，应用从起点沿唯一出边构建播放链。

连线必须形成线性路径：每个节点最多一个前驱和一个后继，且不能形成循环。未连接到起点路径的节点不会进入本次演讲。

## 如何控制提词窗

- 使用设置调整主题、字号、不透明度、捕获保护和默认鼠标穿透。
- 使用默认快捷键跨应用切换节点、滚动内容、隐藏窗口或切换鼠标穿透。
- 提词窗获得键盘焦点时，还可以使用 `Space` / `Right`、`Left`、`PageUp`、`PageDown` 和 `Esc`。
- 内容高度变化时，窗口会自动调整，最大高度由 `maxHeightRatio` 限制。

捕获保护调用 Electron 的 `setContentProtection`。它只代表应用已请求操作系统保护，不代表所有采集链路都会遵守。

## 如何备份和迁移项目

### 导出

1. 打开演讲。
2. 选择顶部“导出备份”。
3. 保存 `.speechdesk` 文件。

备份是 ZIP 容器，包含版本清单、项目 JSON 和项目使用的图片资源。

### 导入

1. 返回资料库并选择“导入备份”。
2. 选择 `.speechdesk` 文件。
3. 应用创建标题带“（导入）”的新项目，不覆盖原项目。

导入器拒绝不支持的备份版本、不安全路径、缺少必要文件或解压后总大小超过 150 MB 的包。结构字段还会经过 Zod 校验。

## 如何恢复或删除项目

- “移到回收站”只写入删除时间，项目仍可恢复。
- “永久删除”会删除数据库记录，并尝试删除已登记的图片文件。此操作不可撤销。
- “创建副本”会生成新的项目、节点、连线和图片 ID，并改写富文本中的本地资源 URL。

## 验证

开发者可以运行：

```powershell
npm.cmd run check
```

当前测试覆盖演讲连线约束、播放链循环保护、Markdown 识别、公式迁移和显示器布局变化后的窗口边界恢复。

## 故障排查

### 无法开始演讲

确认项目存在有效起点，且起点 ID 对应当前项目中的节点。开始演讲前保存失败也会阻止提词窗开启。

### 新快捷键无法保存

至少一个组合已被其他应用占用。应用会注销本次已注册组合，并重新注册上一次设置。关闭冲突应用或改用其他组合。

### 备份无法导入

确认文件是 Talk2 导出的版本 1 `.speechdesk` 文件，且解压后不超过 150 MB。不要手工修改清单路径或项目结构。
